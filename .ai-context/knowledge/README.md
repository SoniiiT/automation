# Project knowledge

`.ai-context/` is the shared context for agents. Generated facts are evidence-backed summaries of the current repository; curated guidance records explicit project decisions or safe operating procedures.

- Generated map, architecture, conventions, dependencies, and indexes should be refreshed from source.
- Knowledge entries must label observations versus inferences and include evidence paths.
- Human-authored decisions and rules must be preserved during refresh. Do not treat this context as a replacement for source code, secrets management, or explicit project instructions.
