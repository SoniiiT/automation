# Scripts & Tools

Dieses Verzeichnis enthält eine Sammlung von Standalone-Skripten, Hilfsprogrammen und Setup-Routinen für verschiedene Betriebssysteme und Anwendungszwecke.

## 📂 Struktur

- **maintenance/**: Skripte für Systemwartung und Hintergrund-Automatisierung.
- **gaming/**: Tools für Gaming-Server und Spiele-Management.
- **setup/**: Generelle Skripte für verschiedene Systeme (Windows, Linux, macOS).
- **utils/**: Nützliche kleine Helfer, Konverter und TUI-Tools.

## 🛠️ Kategorien

### 🔧 Maintenance (`scripts/maintenance/`)
Hier befinden sich Skripte, die Aufgaben im Hintergrund erledigen oder das System sauber halten.

### 🎮 Gaming (`scripts/gaming/`)
Skripte zur Verwaltung von Spiele/-Servern.

### 💻 Setup (`scripts/setup/`)
Generelle Skripte für verschiedene Systeme (Windows, Linux, macOS). Enthält Bootstrap-Skripte zum schnellen Einrichten neuer Maschinen sowie systembezogene Hilfsskripte (z. B. Festplatten auslesen).

Windows-Skripte sind zusätzlich nach Shell und Zweck gruppiert:
- `scripts/setup/windows/powershell/docker/`
- `scripts/setup/windows/powershell/system/`
- `scripts/setup/windows/powershell/autopilot/`

### 🧰 Utils (`scripts/utils/`)
Verschiedene Werkzeuge für spezifische Aufgaben.
