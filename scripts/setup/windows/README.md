# Windows Setup Scripts

Dieses Verzeichnis enthaelt Setup-Skripte fuer Windows und ist nach Shell sowie Themenbereich strukturiert.

## Struktur

- `powershell/docker/`: Docker-bezogene PowerShell-Skripte.
- `powershell/system/`: System-Setup und Systempflege.
- `powershell/autopilot/`: Benutzer- und rollenbezogene Autopilot-Setups.

## Ablage-Regel

Lege neue Windows-PowerShell-Skripte immer in einem thematischen Unterordner unter `powershell/` ab.
Wenn ein neues Thema hinzukommt, erstelle dafuer einen eigenen Unterordner (z. B. `powershell/network/`).
